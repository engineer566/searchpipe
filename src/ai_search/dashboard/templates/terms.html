一、服务说明

SearchPipe（以下简称「本服务」）是由 SearchPipe 团队提供的、面向 AI Agent 的联网搜索服务，通过聚合多引擎检索、网页正文抓取、LLM 重排与摘要，为用户提供结构化搜索结果。用户可通过 MCP Server 方式（Claude Code、Cursor 等 Agent 客户端）或 API 调用接入本服务。

二、积分、充值与订阅（重要：一经售出概不退款）

本服务采用预付费积分制，提供「积分充值」与「包月订阅」两种购买方式。用户购买的积分、充值套餐、订阅套餐或任何付费产品，一经售出概不退款。

搜索请求按次扣减积分：基础搜索（basic）每次扣 1 积分，高级搜索（advanced）每次扣 2 积分。积分不可转让、不可提现、不可兑换为现金。若因本服务端技术故障导致扣费异常，经核实后将以补发积分形式处理，不涉及现金退款。支付方式支持微信支付（以结算页实际可用渠道为准）。

请特别注意积分有效期差异：通过「积分充值」获得的积分永久有效；通过「包月订阅」（含续订、升级）获得的积分非永久有效，自到账起 30 天有效，到期未用完自动清零，不予延期、退款或补偿。

（一）积分充值

  • 兑换汇率：¥0.03 = 1 积分；
  • 固定档位：¥10 = 350 积分，¥20 = 700 积分，¥50 = 1800 积分，¥100 = 5000 积分；
  • 自定义金额：单笔充值上限 ¥100，严格按 ¥0.03 = 1 积分兑换，积分精确到小数点后 2 位；
  • 充值获得的积分永久有效，不设有效期。

（二）包月订阅

  • 订阅档位（限时折扣价 / 标价）：¥9.99（¥19.99）= 1000 积分；¥24.99（¥49.99）= 3000 积分；¥49.99（¥99.99）= 10000 积分。限时折扣可能随时调整或结束，以购买时页面显示的实际售价为准；
  • 订阅积分有效期为自订阅成功（到账）时刻起 30 天，到期未用完的订阅积分自动清零，不予退款或补偿；
  • 本服务不支持自动续订，到期后如需继续使用请手动续订；
  • 续订：续订的积分自下一周期开始时刻生效，有效期 30 天，不累积到当前周期；
  • 升级：升级需支付新档位当前售价的全额（不抵扣原档位剩余价值）。升级后新档位积分即刻到账并自升级时刻起算 30 天有效期；原档位未用完的积分延期至与新档位同期到期；
  • 不支持降级；已订阅用户在订阅有效期内仅可使用续订与升级入口。

扣费时优先消耗即将到期的订阅（限时）积分，永久积分最后消耗。请在购买前充分评估自身需求。如因用户自身原因（包括但不限于账号停用、主动注销、长期未使用等）导致积分无法使用，不予退款或补偿。
