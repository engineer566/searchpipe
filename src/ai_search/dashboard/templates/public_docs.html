开发文档

SearchPipe 提供两种接入方式：给 Agent 用的 远程 MCP Server（推荐），以及给自有管线用的 REST API。两种方式跑的是同一条检索管线，参数与结果结构一致。

快速开始

  1. 注册账号，自动获得免费额度（额度用完后按积分计费，见 定价）。
  2. 进入控制台的 API Keys 页创建一个密钥，形如 sp-xxxxxxxx；创建弹窗会直接给出可用的 MCP 链接。
  3. 把密钥填进 MCP 客户端（推荐），或直接调用 POST /search。

MCP 接入（推荐）

SearchPipe 是远程 MCP Server（streamable-http 传输），API Key 直接内嵌在 URL 里，因此不支持自定义请求头的客户端也能用：

# MCP 链接格式（Key 内嵌在 URL，无需配置请求头）：
{{ site_url }}/mcp?api_key=sp-你的API密钥

# Claude Code 一键添加：
claude mcp add --transport http searchpipe "{{ site_url }}/mcp?api_key=sp-你的API密钥"

# 工具名：ai_search_search（参数与 POST /search 一致）

支持自定义请求头的客户端也可以二选一：URL 用 {{ site_url }}/mcp，并加 Authorization: Bearer sp-… 头。

各客户端的具体配置写法、连接排障见 MCP 接入指南。

Agent 自举配置

把下面的链接发给你的 AI Agent，它可以读取这份说明自行完成 MCP 配置与验证：

{{ site_url }}/agent-setup/SKILL.md

更省事的做法：登录控制台后打开 API Keys 页，点「复制一句话配置」——那段提示词里已经带上你的 API Key 与 MCP 链接，粘贴给 Agent 即可一键接入（出于安全考虑，提示词内容不在页面上展示）。

REST API 认证

程序直接调用 / 自建 Agent 管线时使用 REST API。所有调用需要认证，使用 API Key（创建），支持两种传递方式：

Authorization: Bearer sp-你的密钥
# 或
X-API-Key: sp-你的密钥

POST /search 参数

一次调用完成检索聚合 → 正文抓取 → LLM 重排 →（可选）AI 摘要。与 MCP 工具 ai_search_search 参数一致。

参数类型默认说明
query 必填string—搜索问题或关键词
max_resultsint5返回结果数（1–20）
include_answerboolfalse是否生成带引用的 AI 摘要
include_raw_contentboolfalse是否返回抓取的完整正文
search_depthstringbasic搜索深度（basic / advanced），影响扣费

响应结构

返回结果为结构化 JSON，每条结果带 0–1 的相关性评分，按相关性从高到低排序：

{
  "query": "FastAPI 怎么部署",
  "answer": "FastAPI 可通过 uvicorn 部署，常见做法是配合 gunicorn…[0][2][3]",
  "ai_generated": true,
  "results": [
    {
      "url": "https://…",
      "title": "…",
      "content": "正文摘要片段…",
      "score": 0.98,
      "raw_content": "完整正文（仅 include_raw_content=true 时）"
    }
  ]
}

开启摘要时响应会带上 ai_generated: true，用于标识 AI 生成内容。

调用示例

curl

curl -X POST {{ site_url }}/search \
  -H "Authorization: Bearer sp-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"query":"FastAPI 教程","max_results":5,"include_answer":true}'

Python

import httpx

resp = httpx.post(
    "{{ site_url }}/search",
    headers={"Authorization": "Bearer sp-你的密钥"},
    json={"query": "FastAPI 教程", "max_results": 5, "include_answer": True},
    timeout=60,
)
data = resp.json()
print(data["answer"])
for r in data["results"]:
    print(r["score"], r["title"], r["url"])

JavaScript

const resp = await fetch("{{ site_url }}/search", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sp-你的密钥",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ query: "FastAPI 教程", max_results: 5, include_answer: true }),
});
const data = await resp.json();

错误码

状态码含义处理建议
400输入/输出内容违规调整查询内容；输出违规已自动退款
401认证凭据缺失或无效检查 API Key 是否正确、是否已吊销
402积分不足充值后重试
429触发限流降低并发，按 Retry-After 头稍后重试
502检索源失败已自动退款，可安全重试

限流与计费

  • 限流：Redis 滑动窗口，默认每分钟 100 次、突发 20 次，超限返回 429 并带 Retry-After；管理账号豁免。
  • 计费：基础搜索（basic）1 积分/次，高级搜索（advanced）2 积分/次；失败不扣费，已扣的会幂等退款。
  • 缓存：相同 query 与参数在缓存有效期（默认 300 秒）内直接命中，不重复跑管线。
  • 积分来源：注册赠送、充值（永久有效）、包月订阅（30 天有效），详见 定价。
