One-command MCP setup

SearchPipe is a remote MCP Server (streamable-http) with the API key embedded in the URL — drop it into any MCP-compatible agent client and it just works.

Claude Code

claude mcp add --transport http searchpipe \
  "{{ site_url }}/mcp?api_key=sp-YOUR_API_KEY"

Cursor / generic MCP clients

{
  "mcpServers": {
    "searchpipe": {
      "url": "{{ site_url }}/mcp?api_key=sp-YOUR_API_KEY"
    }
  }
}

Key-in-URL, zero config

The key is embedded in the MCP link (same style as Tavily), so clients without custom-header support work out of the box. Tool name: ai_search_search.

One endpoint, the whole pipeline

Your agent sends a single query; we run search, extraction, scoring and summarization in the background, and return clean results ranked by relevance.

01

Multi-engine retrieval

Aggregates multiple search engines — self-hosted, fully under our control, no third-party search API fees.

02

Extraction & cleanup

Automatically fetches top-N pages and extracts the article body, filtering out navigation, ads and noise.

03

LLM reranking

A large model scores relevance (0–1) against the query intent, so the most relevant results come first.

04

AI answer

Optionally generates a direct answer with citation markers, giving your agent ready-to-consume factual context.
