MCP 一键接入

SearchPipe 是远程 MCP Server（streamable-http），API Key 直接内嵌在链接里——任何兼容 MCP 的 Agent 客户端填入即用。

Claude Code

claude mcp add --transport http searchpipe \
  "{{ site_url }}/mcp?api_key=sp-你的API密钥"

Cursor / 通用 MCP 客户端

{
  "mcpServers": {
    "searchpipe": {
      "url": "{{ site_url }}/mcp?api_key=sp-你的API密钥"
    }
  }
}

URL 内嵌 Key，零配置

Key 编在 MCP 链接里（与 Tavily 同款），不支持自定义请求头的客户端也能直接用。工具名：ai_search_search。

一个端点，整条管线

Agent 发一个 query，我们在后台跑完搜索、抓取、打分、摘要四步，返回带相关性评分的干净结果。

01

多引擎检索

聚合多个搜索引擎，自建可控，零第三方 API 费用。

02

正文抓取清洗

自动抓取 Top-N 页面并提取正文，过滤导航、广告与噪声。

03

LLM 重排

大模型按查询意图打相关性分（0–1），最相关的结果排在前面。

04

AI 摘要

可选生成带引用标注的直接答案，为 Agent 提供可直接消费的事实上下文。

典型使用场景

只要需要「实时、可引用、结构化」的网页事实，SearchPipe 就能替掉你自己维护的检索链路。

编码 Agent 查最新文档

框架版本刚升级、文档刚改版时，让 Claude Code / Cursor 直接检索并读取正文，而不是靠训练数据里的旧记忆。

行业情报与竞品监控

定时跑一组查询，把带评分的正文落地到自有库，用于日报、舆情与价格监控——同 query 命中缓存，成本可控。

客服/问答机器人补事实

用 include_answer 拿到带引用编号的摘要，把「无法回答的时效性问题」变成有出处的答案。

研究工作流自动化

批量 query 并行检索抓取，省掉自建爬虫与反爬维护；失败自动退款，重跑安全幂等。
