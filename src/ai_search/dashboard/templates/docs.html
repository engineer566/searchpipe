开发文档

认证方式、端点参数、响应结构与集成示例。

认证

所有 API 调用需要认证。程序调用使用 API Key（创建），支持两种传递方式：

Authorization: Bearer sp-你的密钥
# 或
X-API-Key: sp-你的密钥

POST /search

一次调用完成检索聚合 → 正文抓取 → LLM 重排 →（可选）AI 摘要。

参数类型默认说明
query 必填string—搜索问题或关键词
max_resultsint5返回结果数（1–20）
include_answerboolfalse是否生成带引用的 AI 摘要
include_raw_contentboolfalse是否返回抓取的完整正文
search_depthstringbasic搜索深度，影响扣费

响应结构

一次调用直接返回结构化结果，带相关性评分。

{
  "query": "FastAPI 怎么部署",
  "answer": "FastAPI 可通过 uvicorn 部署，常见做法是配合 gunicorn…[0][2][3]",
  "ai_generated": true,
  "results": [
    {
      "url": "https://…",
      "title": "…",
      "content": "正文摘要片段…",
      "score": 0.98,
      "raw_content": "完整正文（仅 include_raw_content=true 时）"
    }
  ]
}

调用示例

curl

curl -X POST {{ request.base_url }}search \
  -H "Authorization: Bearer sp-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"query":"FastAPI 教程","max_results":5,"include_answer":true}'

Python

import httpx

resp = httpx.post(
    "{{ request.base_url }}search",
    headers={"Authorization": "Bearer sp-你的密钥"},
    json={"query": "FastAPI 教程", "max_results": 5, "include_answer": True},
    timeout=60,
)
data = resp.json()
print(data["answer"])
for r in data["results"]:
    print(r["score"], r["title"], r["url"])

JavaScript

const resp = await fetch("{{ request.base_url }}search", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sp-你的密钥",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ query: "FastAPI 教程", max_results: 5, include_answer: true }),
});
const data = await resp.json();

错误码

状态码含义处理建议
400输入/输出内容违规调整查询内容；输出违规已自动退款
401认证凭据缺失或无效检查 API Key 是否正确、是否已吊销
402积分不足充值后重试
429触发限流降低并发，稍后重试
502检索源失败已自动退款，可安全重试
