MCP Server 接入指南：让 Claude Code / Cursor 联网搜索

SearchPipe 是一个远程 MCP Server（streamable-http 传输）：把 MCP 链接填进客户端，你的 Agent 就获得实时联网检索、正文抓取与带引用摘要的能力，不需要本地部署任何服务。

什么是 MCP，为什么要用远程 MCP Server

MCP（Model Context Protocol）是给 AI 客户端接入外部工具与数据源的开放协议。传统做法是把搜索服务跑在本地（stdio 传输的 MCP Server），需要装依赖、升级版本、管理进程；远程 MCP Server 把这一切放到服务端，客户端只填一个 URL：

  • 零安装：不用 npm / pip 装包，换机器不用重配。
  • 零运维：检索管线（多引擎聚合、正文抓取、LLM 重排、摘要）由服务端持续迭代。
  • Key 内嵌：SearchPipe 把 API Key 编在 MCP 链接里（与 Tavily 同款），不支持自定义请求头的客户端也能直接使用。
  • 可多端共用：同一个链接可填进 Claude Code、Cursor、Cline 等多个客户端。

四步接入

注册并获取 API Key

注册 SearchPipe 账号后进入控制台，在「API Keys」页创建密钥。创建成功后弹窗会直接给出完整的 MCP 链接，复制它即可。

sp-你的API密钥

拼接 MCP 链接

把 Key 拼到 /mcp 后面，形成完整地址——这就是客户端要填的 URL：

{{ site_url }}/mcp?api_key=sp-你的API密钥

写入客户端配置

按下面的客户端示例填入链接（Claude Code 用命令行，Cursor / Cline / VS Code 用 JSON 配置）。

让 Agent 验证一次检索

在对话里让它「用 ai_search_search 查一下今天的新闻」，看到带链接与摘要的结果就说明接入成功。

Claude Code

一条命令添加（--transport http 指定远程 HTTP 传输）：

claude mcp add --transport http searchpipe \
  "{{ site_url }}/mcp?api_key=sp-你的API密钥"

# 查看已添加的服务
claude mcp list

Cursor / Cline / VS Code

在客户端的 MCP 配置（Cursor 为 ~/.cursor/mcp.json，VS Code 为 .vscode/mcp.json 或用户级配置）中添加一个 mcpServers 条目：

{
  "mcpServers": {
    "searchpipe": {
      "url": "{{ site_url }}/mcp?api_key=sp-你的API密钥"
    }
  }
}

部分客户端要求声明为远程 HTTP 服务，可写成：

{
  "mcpServers": {
    "searchpipe": {
      "type": "http",
      "url": "{{ site_url }}/mcp",
      "headers": { "Authorization": "Bearer sp-你的API密钥" }
    }
  }
}

支持自定义请求头的客户端建议用 Authorization: Bearer 方式，Key 不会出现在 URL 与日志里。

可用工具与参数

MCP Server 暴露一个工具 ai_search_search，参数与 REST API 的 POST /search 完全一致：

参数类型默认说明
query 必填string—搜索问题或关键词
max_resultsint5返回结果数（1–20）
include_answerboolfalse生成带引用编号的摘要
include_raw_contentboolfalse返回抓取的完整正文
search_depthstringbasicbasic / advanced，影响扣费

想看字段级的返回结构，见 开发文档 · 响应结构。

常见连接问题

客户端报 406 Not Acceptable

这是 MCP streamable-http 的正常校验：请求头必须同时接受 JSON 与 SSE。用 curl 手工验证时加 -H "Accept: application/json, text/event-stream"；浏览器直接打开 /mcp 报 406 也属正常，不是服务故障。

直接请求 /mcp 被 307 重定向

端点规范路径是 /mcp/（带尾斜杠）。客户端会自动跟随重定向；用 curl 手工调试时加 -L 或直接请求 /mcp/。

提示无效或已吊销的 Key

检查三点：Key 是否以 sp- 开头；是否在控制台被吊销；复制链接时是否把结尾的 sp-… 截断了。Key 泄露时请在控制台立即吊销并重建。

搜索偶尔较慢

冷启动查询会跑完「多引擎检索 → 正文抓取 → LLM 重排」全链路，通常数秒；相同 query 与参数在缓存有效期（默认 300 秒）内毫秒级返回。
